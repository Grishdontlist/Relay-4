Project: Relay4
Team:  404
Built for Louisiana. Designed to connect communities.

What we’re building: An AI emergency intake and coordination assistant that turns calls into live incident information shared by dispatchers and responders.

What makes it different:
• Local context: Configured Louisiana landmarks, parish names, and service areas help clarify locations.
• Related calls: Suggests when callers describe the same incident; a dispatcher confirms.
• Verifiable facts: Important details link to the caller’s original words; missing information stays “unknown.”
• Instant corrections: Location and hazard updates reach everyone.
• Human control: Dispatchers approve assignments; responders acknowledge receipt.

Technology:
• ElevenLabs: Natural voice conversations, follow-up questions, location confirmation, and tools that update incident facts.
• DeepSpace: Live dashboards, shared records, permissions, assignment status, and correction history.

Demo: Two callers report rising water and a stranded car near a fictional Louisiana landmark. Relay4 suggests a connection, confirms and corrects the location, then shares a human-approved assignment with a simulated responder.

Build order: Voice intake → live incident card → corrections → approval → responder acknowledgement. Add related-call detection next; multilingual support and training mode are extras.

Team split:

1 Voice agent + caller screen.
2 Backend + records + permissions.
3 Dispatcher dashboard + assignments.
4 Responder screen + testing + demo.

Expansion: Start in Louisiana, then configure local landmarks, languages, agencies, and validated procedures for other regions.

Pitch: “Relay4 turns scattered emergency calls into one clear, local picture—starting in Louisiana, with a foundation adaptable to other communities.”

Hackathon scope: synthetic calls, simulated responders, human-approved dispatch.
